# Мой контракт quality gate

Я моделирую выгрузку одной позиции на заказ. order_id уникален в файле среди
принятых записей; это упрощение, многопозиционные заказы потребуют другого ключа.
Цель — не загружать некорректные записи молча и дать конвейеру явное решение.

CSV — UTF-8 без BOM, разделитель запятая, заголовок ровно:
`order_id,ordered_on,sku,quantity,unit_price_minor,currency`.
Порядок полей значим. Blank lines parser пропускает; логический номер относится
к записи данных, не физической строке. Quoted fields и CRLF разрешены CSV parser,
но содержимое проходит строгий бизнес-контракт.

| Поле | Что я принимаю |
| --- | --- |
| order_id, sku | ASCII буква первым символом, затем буквы/цифры/_/-, длина до 32 |
| ordered_on | Существующая дата формата YYYY-MM-DD, без времени |
| quantity | Целое 1…1000000, без знака, leading zeros и пробелов |
| unit_price_minor | Целое 0…1000000000 в minor units, без float/знака/leading zeros |
| currency | RUB, USD или EUR |

Я не исправляю значения trim/округлением. Первая полностью корректная запись
резервирует order_id; последующие корректные с тем же ID отклоняю как DUPLICATE.
Некорректная строка не блокирует исправленную с тем же ID. При нескольких дефектах
возвращаю несколько codes в стабильном порядке, а не исходный payload.

Accepted CSV сохраняет допустимые поля в исходном порядке записей. Rejections
содержит только logical record number, codes и SHA framing исходных полей.
Report содержит SHA всего входа, байты, counts, gate, threshold и суммы по валютам.
Умножение/суммирование выполняю в int64 и проверяю переполнение total до сложения.

Gate fail я сохраняю как законченный результат. Фатальные header/quoting/I/O/limit
ошибки не публикуют output; существующий output не заменяется. File identity
относится к байтам реально прочитанного потока; я не блокирую внешний процесс,
редактирующий input во время чтения, и не заявляю immutable source snapshot.

Критерии моего узкого результата: 8 demo записей → 4 accepted/4 rejected;
порог 0 даёт exit 3, 5000 даёт exit 0; суммы EUR 3000/RUB 39000/USD 2000;
отказ на malformed quoting не оставляет частичного output; повтор не затирает
каталог; библиотек вне стандартной нет. Реальные проверки — VALIDATION.
